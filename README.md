# RegistryToPowershell

RegistryToPowershell is a lightweight and web-based PowerShell script generator from REG files and code created by Justin Verstijnen. This tool can be used to generate PowerShell scripts that set different Registry keys which can be used for Endpoint Managent and Server Management using Microsoft Intune, Group Policy or 3rd party management tools.

## Main features

The main features of this tool are:

- Generate PowerShell scripts from your Reg keys
- Import/Export functionality
- Ready-to-use PowerShell script for Microsoft Intune

## Hosting

This tool is currently hosted on GitHub Pages. Configuration changes are pushed and built using the default deployment method.
